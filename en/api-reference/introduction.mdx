HiLinkup exposes OpenAI-compatible endpoints and selected provider-style compatible endpoints. Most OpenAI-compatible clients only need a new API key, base URL, and model ID. Claude-style and Gemini-style clients must use their own endpoint paths and auth headers.

## Base URLs and full endpoints

When an SDK asks for a **base URL**, use:

```text
https://hilinkup.com/v1
```

When a client asks for a **full endpoint**, use the protocol-specific path:

| Protocol | Base URL | Full endpoint |
| --- | --- | --- |
| OpenAI Responses | `https://hilinkup.com/v1` | `https://hilinkup.com/v1/responses` |
| OpenAI Chat Completions | `https://hilinkup.com/v1` | `https://hilinkup.com/v1/chat/completions` |
| Claude Messages | `https://hilinkup.com` | `https://hilinkup.com/v1/messages` |
| Gemini generateContent | `https://hilinkup.com` | `https://hilinkup.com/v1beta/models/{model}:generateContent` |

<Warning>Do not interchange a base URL and a full endpoint. SDKs normally append the resource path, so using a full endpoint as a base URL can create duplicated paths.</Warning>

## Authentication

OpenAI-compatible endpoints:

```http
Authorization: Bearer YOUR_HILINKUP_API_KEY
Content-Type: application/json
```

Claude Messages-compatible endpoints:

```http
x-api-key: YOUR_HILINKUP_API_KEY
anthropic-version: 2023-06-01
Content-Type: application/json
```

Gemini-compatible endpoints:

```http
x-goog-api-key: YOUR_HILINKUP_API_KEY
Content-Type: application/json
```
