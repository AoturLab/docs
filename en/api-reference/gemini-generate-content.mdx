Use the Gemini-style endpoint when your application already follows Google's Gemini API request shape. Keep `contents`, `parts`, and `generationConfig`; replace the host, API key, and model ID.

<Info>
  Reference format: [Gemini API text generation](https://ai.google.dev/gemini-api/docs/text-generation). HiLinkup supports common text generation structures; capabilities depend on the selected model.
</Info>

<Note>
  “Gemini generateContent” is the protocol shape, not a requirement to use an overseas Gemini model. Examples use the HiLinkup platform model `aliyun/kimi-k3`; confirm available IDs with `/v1/models`.
</Note>

## Endpoint

```text
POST https://api.hilinkup.com/v1beta/models/{model}:generateContent
```

Replace `{model}` with an available Gemini-compatible model ID, for example:

```text
aliyun/kimi-k3
```

## Headers

```http
Content-Type: application/json
x-goog-api-key: $HILINKUP_API_KEY
```

## Minimal request

```bash
curl "https://api.hilinkup.com/v1beta/models/aliyun/kimi-k3:generateContent" \
  -H "x-goog-api-key: $HILINKUP_API_KEY" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "contents": [
      {
        "parts": [
          {
            "text": "Find the race condition in this multi-threaded C++ snippet: [code here]"
          }
        ]
      }
    ]
  }'
```

## Configuration map

| Google Gemini setting | HiLinkup setting |
| --- | --- |
| API key | HiLinkup API key |
| Base URL / endpoint | `https://api.hilinkup.com`, final path `/v1beta/models/{model}:generateContent` |
| Model | A HiLinkup model ID that supports generateContent, such as `aliyun/kimi-k3` |
| Auth header | `x-goog-api-key: $HILINKUP_API_KEY` |

<Warning>
  Gemini does not use `/v1/chat/completions`. If a client asks for a full endpoint, use `https://api.hilinkup.com/v1beta/models/{model}:generateContent`.
</Warning>
