HiLinkup provides a unified model API with OpenAI Responses, Chat Completions, Claude Messages, and Gemini generateContent compatible protocols. Use Responses for new OpenAI-style code; use the protocol that each third-party client actually supports.

<Info>API base URL: `https://api.hilinkup.com/v1`</Info>

## Minimal example

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_HILINKUP_API_KEY",
    base_url="https://api.hilinkup.com/v1",
)

response = client.responses.create(
    model="aliyun/kimi-k3",
    input="Hello",
)
print(response.output_text)
```

<Tip>Call [`GET /v1/models`](/en/api-reference/models) before choosing a model. Availability can vary by account and provider channel.</Tip>

<Note>Chat Completions remains available for existing applications and chat clients that do not implement Responses.</Note>
