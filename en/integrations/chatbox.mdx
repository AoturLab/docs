<Info>This configuration uses Chat Completions. Enter base URL `https://api.hilinkup.com/v1`; Chatbox should send its final request to `POST /v1/chat/completions`.</Info>

Choose a custom OpenAI API provider and configure:

- API key: your HiLinkup API key
- API host: `https://api.hilinkup.com/v1`
- Model: an available HiLinkup model ID

If model discovery is unavailable, enter the exact ID returned by `/v1/models`.
