<Info>This setup uses Chat Completions. Depending on the NextChat version, enter a host or base URL, but the final request must be `https://api.hilinkup.com/v1/chat/completions`.</Info>

For a client configuration, enter the HiLinkup API key, `https://api.hilinkup.com/v1`, and a model ID returned by `/v1/models`.

For a self-hosted deployment, keep credentials in private server environment variables:

```dotenv
OPENAI_API_KEY=your-hilinkup-api-key
BASE_URL=https://api.hilinkup.com
CUSTOM_MODELS=aliyun/kimi-k3
```

<Warning>Some releases append `/v1` automatically. Confirm that the final request URL is `https://api.hilinkup.com/v1/chat/completions`, not `/v1/v1/chat/completions`.</Warning>
