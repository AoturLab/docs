HiLinkup 提供统一的模型 API，并兼容 OpenAI Responses、Chat Completions、Claude Messages 与 Gemini generateContent 等调用协议。新开发的 OpenAI 风格应用优先使用 Responses；第三方客户端应使用它实际支持的协议。

<Info>
  API Base URL：`https://api.hilinkup.com/v1`
</Info>

## 最小调用示例

<CodeGroup>
```python Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_HILINKUP_API_KEY",
    base_url="https://api.hilinkup.com/v1",
)

response = client.responses.create(
    model="aliyun/kimi-k3",
    input="用一句话介绍 HiLinkup",
)

print(response.output_text)
```

```javascript Node.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.HILINKUP_API_KEY,
  baseURL: "https://api.hilinkup.com/v1",
});

const response = await client.responses.create({
  model: "aliyun/kimi-k3",
  input: "用一句话介绍 HiLinkup",
});

console.log(response.output_text);
```

```bash cURL
curl https://api.hilinkup.com/v1/responses \
  -H "Authorization: Bearer $HILINKUP_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aliyun/kimi-k3",
    "input": "用一句话介绍 HiLinkup"
  }'
```
</CodeGroup>

<Tip>
  模型可用性可能随账户和渠道变化。发送请求前，通过
  [`GET /v1/models`](/api-reference/models) 获取当前 API Key 可用的模型 ID。
</Tip>

## 推荐接入顺序

<Steps>
  <Step title="创建 API Key">
    登录 [HiLinkup 控制台](https://hilinkup.com/console/token)，为每个应用创建独立密钥。
  </Step>
  <Step title="获取模型">
    调用 `/v1/models`，不要长期硬编码未经验证的模型列表。
  </Step>
  <Step title="选择正确协议并完成基础调用">
    新项目先测试 Responses；第三方客户端按其文档选择 Chat Completions、Claude Messages 或 Gemini generateContent，再验证高级能力。
  </Step>
  <Step title="接入生产环境">
    配置超时、有限重试、日志脱敏、额度和异常告警。
  </Step>
</Steps>
