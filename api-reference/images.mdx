根据文本提示生成新图像。可用的尺寸、数量、返回格式由具体模型决定。

<Info>
  下面的代码块是完整请求，可以直接复制运行。先把 `HILINKUP_API_KEY` 设为你的真实密钥，并把 `model` 替换为 `GET /v1/models` 返回的图像模型 ID。
</Info>

## 请求参数

<ParamField body="model" type="string" required>
  支持图像生成的模型 ID。使用 `GET /v1/models` 获取当前可用值。
</ParamField>

<ParamField body="prompt" type="string" required>
  描述目标图像的文本提示。
</ParamField>

<ParamField body="n" type="integer" default="1">
  要生成的图像数量。部分模型只支持 `1`。
</ParamField>

<ParamField body="size" type="string">
  图像尺寸，例如 `1024x1024`。可用值由模型决定。
</ParamField>

## 请求示例

<CodeGroup>
```bash cURL
curl https://api.hilinkup.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HILINKUP_API_KEY" \
  -d '{
    "model": "aliyun/qwen-image-3.0",
    "prompt": "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
    "n": 1,
    "size": "1024x1024"
  }'
```

```python Python
import os

import requests

API_KEY = os.environ["HILINKUP_API_KEY"]
BASE_URL = "https://api.hilinkup.com/v1"

response = requests.post(
    f"{BASE_URL}/images/generations",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "aliyun/qwen-image-3.0",
        "prompt": "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
        "n": 1,
        "size": "1024x1024",
    },
    timeout=300,
)
response.raise_for_status()

result = response.json()
print(result["data"][0]["url"])
```

```javascript Node.js
const apiKey = process.env.HILINKUP_API_KEY;

const response = await fetch("https://api.hilinkup.com/v1/images/generations", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "aliyun/qwen-image-3.0",
    prompt: "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
    n: 1,
    size: "1024x1024",
  }),
});

if (!response.ok) {
  throw new Error(`请求失败 ${response.status}: ${await response.text()}`);
}

const result = await response.json();
console.log(result.data[0].url);
```
</CodeGroup>

## 响应

<ResponseExample>
```json
{
  "created": 1782972000,
  "data": [
    {
      "url": "https://api.hilinkup.com/v1/images/files/img_8f3c1a2b.png"
    }
  ]
}
```
</ResponseExample>

<ResponseField name="created" type="integer">
  生成结果的 Unix 时间戳。
</ResponseField>

<ResponseField name="data" type="array">
  图像结果列表，每项包含 `url` 或 `b64_json`。
</ResponseField>

<Note>
  返回值可能是临时 URL，也可能是 Base64 数据（通常为 `b64_json` 字段）。请在有效期内下载并保存结果，不要长期依赖返回的 URL。
</Note>

## 保存生成结果

```python
import requests

image_url = result["data"][0]["url"]

image = requests.get(image_url, timeout=60)
image.raise_for_status()

with open("output.png", "wb") as file:
    file.write(image.content)
```

<Warning>
  示例中的模型 ID、响应字段和 URL 仅用于说明请求格式。请先通过模型列表或控制台确认当前账户可用的图像模型，以及该模型支持的尺寸和 `n` 取值。
</Warning>
