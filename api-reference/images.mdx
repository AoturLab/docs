根据文本提示生成图像，或基于已有图像做局部编辑。可用的尺寸、数量、返回格式由具体模型决定。

<Info>
  以下代码块是完整请求，可直接复制运行。先把 `HILINKUP_API_KEY` 设为你的真实密钥，并把 `model` 替换为 `GET /v1/models` 返回的图像模型 ID。
</Info>

## `POST /v1/images/generations`

根据文本提示生成新图像。

<ParamField body="model" type="string" required>
  支持图像生成的模型 ID。使用 `GET /v1/models` 获取当前可用值。
</ParamField>

<ParamField body="prompt" type="string" required>
  描述目标图像的文本提示。
</ParamField>

<ParamField body="n" type="integer" default="1">
  要生成的图像数量。部分模型只支持 `1`。
</ParamField>

<ParamField body="size" type="string">
  图像尺寸，例如 `1024x1024`。可用值由模型决定。
</ParamField>

### 请求示例

<CodeGroup>
```bash cURL
curl https://api.hilinkup.com/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HILINKUP_API_KEY" \
  -d '{
    "model": "aliyun/qwen-image-3.0",
    "prompt": "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
    "n": 1,
    "size": "1024x1024"
  }'
```

```python Python
import os

import requests

API_KEY = os.environ["HILINKUP_API_KEY"]
BASE_URL = "https://api.hilinkup.com/v1"

response = requests.post(
    f"{BASE_URL}/images/generations",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "aliyun/qwen-image-3.0",
        "prompt": "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
        "n": 1,
        "size": "1024x1024",
    },
    timeout=300,
)
response.raise_for_status()

result = response.json()
print(result["data"][0]["url"])
```

```javascript Node.js
const apiKey = process.env.HILINKUP_API_KEY;

const response = await fetch("https://api.hilinkup.com/v1/images/generations", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    model: "aliyun/qwen-image-3.0",
    prompt: "一只橘猫坐在窗边，午后阳光，写实摄影风格。",
    n: 1,
    size: "1024x1024",
  }),
});

if (!response.ok) {
  throw new Error(`请求失败 ${response.status}: ${await response.text()}`);
}

const result = await response.json();
console.log(result.data[0].url);
```
</CodeGroup>

## `POST /v1/images/edits`

基于已有图像和文本提示生成修改后的图像。使用 `multipart/form-data` 提交，图像文件字段名通常为 `image`。

<ParamField body="model" type="string" required>
  支持图像编辑的模型 ID。并非所有图像生成模型都支持编辑。
</ParamField>

<ParamField body="prompt" type="string" required>
  描述修改目标的文本提示。
</ParamField>

<ParamField body="image" type="file" required>
  要编辑的原图文件。同一模型对不同格式和大小有不同限制。
</ParamField>

<ParamField body="n" type="integer" default="1">
  要生成的图像数量。部分模型只支持 `1`。
</ParamField>

<ParamField body="size" type="string">
  输出图像尺寸。可用值由模型决定。
</ParamField>

### 请求示例

<CodeGroup>
```bash cURL
curl https://api.hilinkup.com/v1/images/edits \
  -H "Authorization: Bearer $HILINKUP_API_KEY" \
  -F "model=aliyun/qwen-image-3.0" \
  -F "prompt=给图中的猫戴上红色围巾，保持背景和构图不变。" \
  -F "image=@input.png"
```

```python Python
import os

import requests

API_KEY = os.environ["HILINKUP_API_KEY"]
BASE_URL = "https://api.hilinkup.com/v1"

with open("input.png", "rb") as image:
    response = requests.post(
        f"{BASE_URL}/images/edits",
        headers={"Authorization": f"Bearer {API_KEY}"},
        data={
            "model": "aliyun/qwen-image-3.0",
            "prompt": "给图中的猫戴上红色围巾，保持背景和构图不变。",
        },
        files={"image": ("input.png", image, "image/png")},
        timeout=300,
    )
response.raise_for_status()

result = response.json()
print(result["data"][0]["url"])
```

```javascript Node.js
import { openAsBlob } from "node:fs";

const apiKey = process.env.HILINKUP_API_KEY;

const form = new FormData();
form.append("model", "aliyun/qwen-image-3.0");
form.append("prompt", "给图中的猫戴上红色围巾，保持背景和构图不变。");
form.append("image", await openAsBlob("input.png"), "input.png");

const response = await fetch("https://api.hilinkup.com/v1/images/edits", {
  method: "POST",
  headers: { Authorization: `Bearer ${apiKey}` },
  body: form,
});

if (!response.ok) {
  throw new Error(`请求失败 ${response.status}: ${await response.text()}`);
}

const result = await response.json();
console.log(result.data[0].url);
```
</CodeGroup>

## 响应格式

两个端点返回相同的结构。

<ResponseExample>
```json
{
  "created": 1782972000,
  "data": [
    {
      "url": "https://example-cdn.invalid/generated-image.png"
    }
  ]
}
```
</ResponseExample>

<ResponseField name="created" type="integer">
  生成结果的 Unix 时间戳。
</ResponseField>

<ResponseField name="data" type="array">
  图像结果列表，每项包含 `url` 或 `b64_json`。
</ResponseField>

<Note>
  返回值可能是临时 URL，也可能是 Base64 数据（通常为 `b64_json` 字段）。请根据实际响应及时下载并保存生成结果。
</Note>

## 保存生成结果

如果响应返回临时 URL，请在有效期内下载到本地。

```python
import requests

image_url = result["data"][0]["url"]

image = requests.get(image_url, timeout=60)
image.raise_for_status()

with open("output.png", "wb") as file:
    file.write(image.content)
```

<Warning>
  示例中的模型 ID 仅用于说明请求格式。请先通过模型列表或控制台确认当前账户可用的图像模型，以及该模型是否支持编辑、目标尺寸和 `n` 取值。
</Warning>

<Warning>
  示例响应用于说明字段结构。`created`、URL 和图像内容以实际请求为准。
</Warning>
