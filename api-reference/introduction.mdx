HiLinkup API 使用 HTTPS 和 JSON，并提供多种常见模型协议的兼容端点。多数 OpenAI 兼容应用只需要替换 API Key、Base URL 和模型 ID；Claude 与 Gemini 风格应用需要使用各自协议的路径和鉴权头。

## Base URL 与完整 Endpoint

SDK 或客户端要求 **Base URL** 时，OpenAI 兼容协议填写：

```text
https://api.hilinkup.com/v1
```

客户端要求 **完整 Endpoint** 时，按协议填写完整路径：

| 协议 | Base URL | 完整 Endpoint |
| --- | --- | --- |
| OpenAI Responses | `https://api.hilinkup.com/v1` | `https://api.hilinkup.com/v1/responses` |
| OpenAI Chat Completions | `https://api.hilinkup.com/v1` | `https://api.hilinkup.com/v1/chat/completions` |
| Claude Messages | `https://api.hilinkup.com` | `https://api.hilinkup.com/v1/messages` |
| Gemini generateContent | `https://api.hilinkup.com` | `https://api.hilinkup.com/v1beta/models/{model}:generateContent` |

<Warning>
  Base URL 与完整 Endpoint 不能互换。SDK 通常会自动追加路径；如果把完整 Endpoint 当作 Base URL，最终可能出现 `/responses/responses` 或 `/v1/v1/messages`。
</Warning>

## 模型 ID 与供应商

`GET https://api.hilinkup.com/v1/models` 返回的 `owned_by` 表示供应商，`id` 使用 `供应商/模型` 格式。请求中填写 `aliyun/kimi-k3` 会显式使用 `aliyun`；只填写 `kimi-k3` 时，平台会使用当前默认供应商设置。

<Tip>
  需要固定供应商时，始终复制模型列表返回的完整 `data[].id`。供应商列表和平台默认供应商都可能变化。
</Tip>

## 认证

OpenAI 兼容接口：

```http
Authorization: Bearer YOUR_HILINKUP_API_KEY
Content-Type: application/json
```

Claude Messages 兼容接口：

```http
x-api-key: YOUR_HILINKUP_API_KEY
anthropic-version: 2023-06-01
Content-Type: application/json
```

Gemini 兼容接口：

```http
x-goog-api-key: YOUR_HILINKUP_API_KEY
Content-Type: application/json
```

## 主要端点

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/chat/completions` | 创建文本或多模态对话 |
| `POST` | `/responses` | 新项目默认的 OpenAI Responses 兼容接口 |
| `POST` | `/messages` | 使用 Claude Messages 兼容格式创建响应 |
| `POST` | `/v1beta/models/{model}:generateContent` | 使用 Gemini 兼容格式生成内容 |
| `GET` | `/models` | 获取当前密钥可用的模型 |
| `POST` | `/embeddings` | 创建向量表示 |
| `POST` | `/images/generations` | 创建图像 |

<Note>
  端点和参数是否可用取决于模型、账户和上游渠道。调用能力端点前，先确认模型列表与控制台展示。
</Note>

## 请求 ID

错误响应和响应头可能包含请求 ID。联系支持时提供请求 ID、时间、端点和模型 ID，但不要提供 API Key。

## 错误结构

```json
{
  "error": {
    "message": "Invalid token",
    "type": "new_api_error",
    "code": ""
  }
}
```
